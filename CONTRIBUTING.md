# Contributing to Unitsky String Technologies

Thank you for your interest in contributing!

## Ways to Contribute

- **Report bugs** — open an [issue](../../issues/new?template=bug_report.md)
- **Suggest features** — open a [feature request](../../issues/new?template=feature_request.md)
- **Improve documentation** — PRs to `README.md`, `docs/` or `config/explorer/index.html`
- **Mining optimizations** — improvements to `miner/gpu_engine.py` or `miner/cpu_engine.py`
- **Smart contract audits** — review of `contracts/USSTMine.sol`

## Development Setup

```bash
git clone https://github.com/klaren1987/unitsky-chain.git
cd unitsky-chain
pip install -r requirements.txt
```

See [README.md](README.md) for full setup instructions.

## Code Style

- Python: PEP 8
- Solidity: [Solidity style guide](https://docs.soliditylang.org/en/latest/style-guide.html)
- Keep PRs focused and small
